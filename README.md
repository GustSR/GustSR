## 🧭 Como eu trabalho

</div>

|  |  |
| :--- | :--- |
| **Produção é a referência** | Migração ou refatoração só fecha depois de comparação A/B contra o resultado real de produção. |
| **Carga incremental** | Teste de volume começa pequeno e sobe até o ponto que interessa — não se descobre gargalo de I/O em dataset de brinquedo. |
| **Documentação junto do código** | Runbook, decisão de arquitetura e padrão de falha conhecido moram no repositório, não na cabeça de quem escreveu. |
| **Segredo fora do Git** | Cofre versionado, política de risco por sistema e o mínimo de privilégio que resolve. |
| **Read-only até provar o contrário** | Diagnóstico e perícia se fazem sem alterar o alvo. |
